# 2026-11-12 모아+ 추천 학습 단어 화면 논의

> 관련: [[00 모아+ 추천 개발 현황]] · [[2026-11-11 모아+ 추천 인계 받음]] · [[추천 개선 아이디어]]

1. 사용자 물음: 단어 추천은 첫 글자만 보나 → 아님. 입력 중인 단어 전체를 자모로 풀어 앞부분 맞춤(PredictionEngine.suggestions · matchKey). 「감」→ 감사합니다 · 감정평가 · 감정평가사, 「감정」→ 감정평가 · 감정평가사. 단위 테스트 PredictionEngineTests 에 같은 꼴 있음
2. 사용자 물음: 추천 단어를 어디에 보관하나 → prediction-model.json 하나. App Group 공유 폴더 먼저, 못 쓰면 키보드 자기 폴더(PredictionStore). 단어(쓴 횟수 · 점수 · 마지막 사용) 5,000개까지 · 단어 짝 단어마다 20개 · 효과 숫자. 문장은 안 담음. 처음 잠금 해제 전 못 읽게 잠금. 백업에서 빼는 설정 없음 — iCloud 백업 포함 여부는 Apple 문서로 미확인(여쭘)
3. 사용자: 보고 고치려면? → 지금 보는 화면 없음(길게 눌러 지우기 · 모두 지우기만). 사용자 1가(앱 안 화면) · 2나(지우기 + 고치기 + 넣기)
   - 안: 입력 동작 › 「학습한 단어」 화면(검색 · 정렬 · 밀어 지우기 · 눌러 고치기 · ＋ 넣기)
   - 걸림돌(코드 확인): 키보드는 처음 뜰 때 파일을 읽어 들고 있다가 덮어씀(KeyboardViewModel 262 · savePredictionNow) → 앱이 파일을 바로 고치면 지워짐. 그래서 앱은 요청만 남기고 키보드가 반영(학습 데이터 지우기의 predictionResetToken 과 같은 방식)
   - 여쭌 것: 1 새 단어 바로 추천? 2 고칠 때 횟수 이어받기? 3 배우지 않는 단어 규칙 적용? 4 단어 짝 보여 주기?
4. 사용자 「가 가 나 나」: 1가 넣자마자 추천(쓴 횟수 2) · 2가 고치면 옛 횟수 · 순위 이어받음 · 3나 배우지 않는 단어 규칙 적용 안 함 · 4나 단어 누르면 뒤에 자주 쓴 단어 보여 줌(보기만)
   - 3나 의 걸림(코드 확인): ① 엔진이 뜰 때 규칙에 안 맞는 단어를 비움(PredictionEngine.init) → 손으로 넣은 단어 표시가 있어야 낱자모 단어가 남음 ② 단어로 치는 글자는 글자와 ' 뿐(isWordCharacter) → 숫자 · 기호 · 띄어쓰기가 든 것은 넣어도 추천에 안 나옴. 여쭘: 가 넣을 때 막고 알림 / 나 끊는 규칙까지 바꿈(저절로 배우기에도 영향)
5. 사용자 「추천 단어 학습만 구현해 보자」 → 1가(학습한 단어 화면) · 2나 → 숫자를 일부러 안 배우던 까닭(전화번호 · 인증번호) 알리고 다시 여쭘 → 1가(숫자 · 기호는 직접 넣은 단어만, 저절로 배우기는 그대로) · 2가(띄어쓰기 · 문장부호 . , ? ! ; : · 괄호 · 따옴표 뺀 기호 허용)
6. 만듦(커밋 전):
   - 엔진(PredictionEngine): manualWords · appliedEditId(저장 형식에 더함, 옛 파일도 읽음) · 편집 요청 PredictionEdit(add / delete / rename) · apply(edits:) · 넣은 단어 = 쓴 횟수 2 · 고치면 횟수 · 순위 · 짝 이어받기(같은 단어 있으면 합침) · 직접 넣은 단어는 규칙 정리에서 빠짐 · 숫자 · 기호는 직접 넣은 단어(의 앞부분)일 때만 넓게 읽음(suggestionContext · completedWordConsideringManual)
   - 저장(PredictionStore): prediction-edits.json(App Group) · appendEdit · 지우기 때 요청 파일도 지움
   - 키보드: 뜰 때 · 호스트 복귀 때 applyPendingPredictionEdits(지우기 먼저) · 「A-4」 치는 도중 「A」 따로 안 배움
   - 앱: 입력 동작 › 학습한 단어(PredictionWordsView — 많이 쓴 순 / 가나다 순 · 찾기 · 밀어 지우기 · 눌러 고치기 · 뒤에 자주 쓴 단어 · ＋ 넣기) · 설정 검색어 · 설명 문구
   - 테스트 12개 더함(엔진 10 · 뷰모델 2) · CLAUDE.md · CHANGELOG
