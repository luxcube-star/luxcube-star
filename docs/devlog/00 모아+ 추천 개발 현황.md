# 모아+ 추천 개발 현황

> 이름 (사용자가 정함, 2026. 11. 11.): 「새모아」 = 우리가 개발하는 「모아+ 추천」 · 「원모아」 = 원본 모아+ (koh0001/moa-plus, 앱스토어판 포함) · 아이폰에 보이는 이름 「모아+ 추천」과 아이콘은 그대로 둠

- 저장소: `luxcube-star/luxcube-star` · 브랜치 `claude/moaplus-app-search-ko18nf`
- 기반: [모아+](https://github.com/koh0001/moa-plus) v2.2.7 build 33 (MIT, 2026. 11. 11. 합침)
- 기기: iPhone 14 Pro Max · iOS 27.0.1 · 오른손 입력
- 설치: GitHub Actions 로 IPA 빌드 → 아이폰 AltStore ＋ 로 IPA 설치 (Keep App Extensions · 집 Wi-Fi · 맥미니 AltServer 켜져 있어야 함). 2026. 11. 11. 부터 AltStore My Apps 에 올라 있음
- 무료 Apple 계정 → 7일 기한, AltStore 가 뒤에서 갱신(같은 Wi-Fi + 맥미니 AltServer 필요). 안 되면 손수 Refresh 또는 맥미니 AltServer `Option+클릭 › Sideload .ipa...`
