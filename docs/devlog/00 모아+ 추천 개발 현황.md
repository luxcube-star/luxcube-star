# 모아+ 추천 개발 현황

- 저장소: `luxcube-star/luxcube-star` · 브랜치 `claude/moaplus-app-search-ko18nf`
- 기반: [모아+](https://github.com/koh0001/moa-plus) v2.2.6 build 32 (MIT)
- 기기: iPhone 14 Pro Max · iOS 27.0.1 · 오른손 입력
- 설치: GitHub Actions 로 IPA 빌드 → 맥미니 AltServer `Option+클릭 › Sideload .ipa...`
- 무료 Apple 계정 → 7일마다 재설치 (AltStore 앱 로그인 503 해결 전까지)

## 기능
| 기능 | 상태 |
|---|---|
| 학습형 단어 추천 바 | 완료 · 테스트 통과 · 실기기 미확인 |
| 이름 "모아+ 추천" (기본 Info.plist 는 MoaPlus Recommend) | 완료 |
| 주황 아이콘 | 완료 |
| 긋기 미리보기: 완성 글자 · 위치(오른손=왼쪽 위) · 기본 ON | 완료 · 실기기 미확인 |
| 앱 설정 → 키보드 공유 (App Group) | 수정 중 · 실기기 미확인 |

## 미해결
- [ ] 앱 설정(클래식)이 키보드에 반영 안 됨 → run 42827220954 IPA(App Group entitlements 포함) 설치 후 확인
- [ ] AltStore 앱 내 로그인 HTTP 503 (AltStore #1842, 공식 수정 대기)
- [ ] 사용자 보고 "그 밖의 오류" 목록 받기
