# 2026-11-28 모아+ 추천 구역 보기 사라짐

> 앞 기록: [[2026-11-27 모아+ 추천 햅틱 늦음 리포트]] · 현황: [[00 모아+ 추천 개발 현황]]

1. 사용자 「구역 보기가 보였다 안 보였다 하네. 다른 앱을 열어 확인한 뒤 돌아오면 없어지는 것 같은데 확실하지 않아」 — 처음엔 새모아 안드로이드 창에서 읽기만 하며 살펴봄. 사용자 「안드로이드는 잊어 버려. 지금까지의 문제는 iOS 의 문제였어」 → 이 창이 iOS 일을 이어받음
2. 코드로 확인한 것: 스위치(`showVowelZoneOnPress`)는 자음 키를 누를 때마다 `KeyboardSettings.shared` 에서 읽음(`gestureStarted`). 앱 복귀(`NSExtensionHostDidBecomeActive`)는 전체 접근 ON 일 때 `loadAll()` + 제스처 상태 비우기 — 둘 다 스위치를 끄지 않음. 스위치에 값을 쓰는 곳은 앱 설정 화면 토글 하나(+ `resetAll`, 부르는 곳 없음)
3. 그리는 조건(KeyboardView 355–364): 구역 재료 · 시작점 · 활성 키 있음 + 롱키 팝업 없음 + 한글 모드
4. 사용자 시험 ① 다른 앱 다녀온 뒤 윗줄 · 아랫줄 → ㅋ 만 안 보임 ② 조금 뒤 「모든 자음에 구역이 안 보여」
5. 리포트(11/28 10:28, iPhone15,3 · iOS 27.2.1 · v2.3.1 (35) · 전체 접근 ON · 레이아웃 classic11 · 롱프레스 딜레이 1.0초): 조기 터치 10:27:17~ 아래쪽 터치 24 · 키 찾음 24 · **겹침 24** · SwiftUI 먼저 아래쪽 16(모두 같은 키) · 놓침 늦음 150ms 아래 11 · 150~500ms 4 · 500ms 넘음 1. 겹침은 누름을 늦게 할 뿐 구역을 지우지 못함 — 윗줄까지 사라진 것은 설명 못 함
6. 키보드가 쓴 줄(키보드 실측 · 텍스트 대치 「키보드가 읽은 설정」 10:28:29)이 앱 리포트에 보임 → 앱과 키보드는 같은 App Group(group.com.moaki.keyboard.D32N6L7P66)을 씀. AltStore 이름 엇갈림 아님
7. 사용자 시험 (가 가 나 가): 1 앱 스위치 켜짐 · 2 앱 「긋기 실시간 테스트」 미리보기에는 구역 보임 · 3 지구본으로 다른 키보드 갔다 와도 안 보임 · 4 **앱에서 스위치를 껐다 켜니 돌아옴** → 그전까지 키보드는 스위치를 「꺼짐」으로 들고 있었다(앱 화면은 켜짐). 왜 엇갈렸는지는 지금 기록으로 가를 수 없음 — 키보드가 들고 있던 값 · 저장소에서 바로 읽은 값 · 마지막으로 읽은 때를 남기는 진단이 필요
8. 사용자 「구현해」(가 = 진단만, 동작은 그대로): 개발자 리포트에 「구역 보기」 줄 — 앱 쪽(앱 스위치 · 앱이 저장소에서 바로 읽은 값) / 키보드 쪽(`VowelZoneDiagnostics` — 이 실행 시작 · 자음 누름 · 구역 띄움 · 마지막 누름 때 키보드가 들고 있던 값과 저장소에서 바로 읽은 값 · 어긋남 수와 마지막 시각 · 마지막으로 설정을 다시 읽은 때 · 계기(처음 켜짐 · 키보드 만듦 · 키보드 뜸 · 앱에서 돌아옴 · 앱이 바꿨다는 알림) · 그때 읽은 값 · 앱 알림 받음 / 0.1초 안에 겹쳐 버림). `loadAll(reason:)` 로 계기를 받음(기본 「기타」 — 검사 코드 그대로). 적는 때: 첫 누름 · 이 실행의 첫 어긋남은 바로, 그 밖엔 2초에 한 번 + 키보드 내려갈 때 · 백그라운드 갈 때. 앱 미리보기(previewMode)는 안 셈. 글자는 안 적음. 고친 파일: KeyboardSettings · KeyboardViewModel · KeyboardViewController · VowelZoneOverlayView · DebugBoardView · CLAUDE.md, 검사 VowelZoneDiagnosticsTests 3개. 맥미니 문법 검사 통과 + 진단 셈 부분만 떼어 실행해 줄 모양 확인
9. 판독법: 다음에 또 안 보이면 리포트 「구역 보기」 줄 — 키보드 값 꺼짐 · 저장소 값 켜짐(어긋남 > 0) = 키보드가 다시 읽기를 놓침 / 둘 다 꺼짐인데 앱 스위치 켜짐 = 키보드 쪽 저장소가 낡은 값을 줌 / 「겹쳐 버림」 > 0 이면 앱 알림을 버린 적 있음
